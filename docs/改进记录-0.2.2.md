# 0.2.2 审查、改进与桌面交付

审查基线为 `1181c25`。项目已有 Electron、React 和 SQLite 桌面结构，扫描、安装计划、快照恢复与 IPC 保护已有较多回归覆盖。本次沿用现有架构，优先修复可复现的文件保护与界面状态缺陷，并完成 Windows x64 的本地交付。后续按用户要求将源码推送至 [PR #1](https://github.com/jonesq211997494/skill-manager/pull/1)，并补充安装生命周期验证；未发布 GitHub Release。

## 修复与依据

| 问题 | 修复 | 验证 |
| --- | --- | --- |
| 只检查目标是否位于只读目录内部，更新或移除父技能时可能连带改动只读子目录 | `assertWritable` 检查父、子两个包含方向，计划及执行前均复核归属 | 5 条新增用例修复前失败、修复后通过，覆盖系统扫描根、只读技能及预览后的归属变化 |
| Escape 关闭面板没有作废未完成请求，迟到响应会重新打开详情或显示旧错误 | 关闭按钮和 Escape 共用请求失效逻辑 | 浏览器中的延迟成功与延迟失败回归 |
| 扫描只刷新列表，详情与批量选择可能保留过期数据 | 扫描与初始读取共用快照应用流程，同步详情、清理失效选择并作废旧详情请求 | 扫描后正文更新、旧请求忽略和移除后选择清理回归 |
| 桌面窗口提前展示、重复启动未显式恢复最小化状态 | 首次绘制完成后显示，重复启动恢复主窗口；设置 Windows 应用标识 | 正常首次显示、真实第二进程启动、原窗口从最小化恢复均通过，无额外窗口 |
| 当前版本只有解包目录，打包验证遗漏生成的 JS/CSS | 生成安装器及便携 EXE；比较全部第一方文件、运行时版本与生产 CSP，验证最终便携程序 | `package-smoke.mjs`、`portable-smoke.mjs` |
| 固定测试目录可能残留设置、数据库或进程锁 | 桌面与成品测试使用每次独立目录，清理开发地址变量，单独创建报告目录；便携失败收尾限定本次进程树 | 重复运行及隔离扫描 |
| 成品缺少自动校验、CI 不验证实际包 | 自动生成当前版本的 SHA-256 清单；篡改和缺包回归；CI 增加打包与成品检查 | `package-checksums.test.mjs` 与 `test:package` |
| 云端便携程序在 Windows 短路径中被误判为非法 IPC 来源 | 统一 `~` 与 `%7E` 等 URI 非保留字符的等价编码，保留来源、主框架与路径边界校验 | 真实 8.3 临时目录复现 `INVALID_SENDER`；增加等价编码和伪装路径回归，便携测试固定覆盖带 `~` 的解包目录 |

初次受限环境测试遇到 `%TEMP%` 上级目录的 `realpath` 权限错误，将测试临时目录设为项目 `.runtime/test-temp` 后通过。Electron 在本机执行沙箱内遇到 Chromium 运行时访问限制，桌面回归在沙箱外以同一隔离测试脚本完成。生产应用的 Chromium 沙箱和权限配置保留启用。

补验使用每次新建的 GitHub 托管 Windows 环境，安装器仍使用真实 appId 和默认 `%APPDATA%/SkillManagerDesktop`。脚本先拒绝既有安装和用户数据，再核对当前及 v0.2.0 Release 安装包的 SHA-256、PE 版本。验证当前版本全新安装、启动、快捷方式和卸载注册；卸载后逐文件核验数据库、技能及备份保留。随后安装真实 0.2.0，由旧程序创建设置和技能数据，升级到 0.2.2，检查旧数据可读且重新扫描可用，再次卸载并核验数据。脚本拒绝在本机开发账户运行。

150% 布局使用 Chromium `--force-device-scale-factor=1.5`，实际 DPR 为 1.5；本机 Windows 系统缩放为 200%。这一结果不替代 Windows 显示设置切换或多显示器 DPI 切换测试。

补验期间保留失败记录：首次云端成品测试暴露短路径 URI 编码差异，本地使用真正的 8.3 TEMP 路径成功复现后修复；另一次安全冒烟等待首窗口超过 30 秒，现与启动等待统一为 60 秒，并在失败时输出实际窗口状态供诊断。安装生命周期检查在构建成功后独立执行，便携或窗口测试失败仍会使整个 CI 失败，不会被后续检查掩盖。

## 构建与交付

```powershell
npm ci
npm run package:verified
```

`release/` 中当前版本的交付文件：

- `Skill-Manager-0.2.2-setup-x64.exe`
- `Skill-Manager-0.2.2-portable.exe`
- `SHA256SUMS-0.2.2.txt`

便携版与安装版使用同一默认数据位置 `%APPDATA%/SkillManagerDesktop`。升级前先关闭旧程序；需要备份时关闭程序后备份整个数据目录。构建命令显式使用 `--publish never`，CI 不上传测试报告或安装包。测试报告位于本地 `test-results/`。
