# Skillspace 0.2.0 开发预览版

本版补齐现有外部技能的版本跟踪流程，并修复扫描状态、详情显示和文件恢复边界问题。

## 新功能

- 详情中可手动关联 GitHub 仓库内的具体技能，先比较完整内容，再确认保存来源；不移动、覆盖原技能，也不把外部文件改为受管理安装。
- 未知历史基线且内容不同时显示“与来源不同”；只有完整内容一致才建立可靠比较基线。
- 设置中可统计应用目录内的快照、版本副本、技能库、缓存和暂存用量，并按快照阈值提醒。
- 扫描、重复分析、更新检查和来源读取可取消；文件变更操作不会被伪装成可取消的查询。
- 可以移除项目登记，原项目和技能文件保留。

## 修复

- 编辑 SKILL.md 后，详情正文、元数据和健康状态同步刷新。
- 移除扫描范围不再将旧条目误报为文件缺失；重新登记后保留原来的别名、标签和收藏。
- 部分根扫描失败不再影响其他已完成根的状态；未完成根的别名和只读归属会保留。
- 外部工具替换同路径目录时保留管理身份，并使旧版本证据失效。
- 更新检查期间解绑或改绑来源，不会被旧请求恢复或覆盖。
- 操作执行前复查新增 Git 工作区；恢复计划与执行均检查原快照指纹，拒绝被修改的快照。

## 下载与升级

- `Skill-Manager-0.2.0-portable.exe`：便携版。
- `Skill-Manager-0.2.0-setup-x64.exe`：Windows 安装程序。
- `SHA256SUMS-0.2.0.txt`：文件校验值。

请先关闭旧窗口再启动新版。现有应用数据和 GitHub 登录继续使用；源码仓库不会包含账号凭据、本地技能清单或运行数据库。

本版仍为开发预览：原生工具启停、真实会话完整联调及自动备份清理尚未开放；程序没有商业代码签名。
