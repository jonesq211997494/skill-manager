# Skillspace 0.1.2 开发预览版

面向 Windows x64 的中文桌面 Skill 管理器，用于管理 Codex、Claude Code 和 Cursor 的本地技能。

## 下载与运行

- `Skill-Manager-0.1.2-portable.exe`：便携版，下载后直接启动，无需 Node.js 或 Rust。
- `Skill-Manager-0.1.2-setup-x64.exe`：Windows 安装程序。
- `SHA256SUMS-0.1.2.txt`：上述两个文件的 SHA-256 校验值。

升级前关闭旧版窗口。现有应用数据、收藏、别名和技能安装记录继续保存在本机。

## 功能

- 三工具用户级和项目级扫描，识别容器、Junction、断链与插件只读目录。
- 搜索、中文别名、标签、收藏、文件清单及 Markdown 预览。
- GitHub 浏览器授权与 Token 登录，本机加密保存凭据；缓存复用、限流冷却和恢复时间提示。
- 安装预览、更新比较、移除、快照和可恢复操作。
- 列表版本状态：已是最新、有更新、本地修改、待检查及来源未知；支持按工具和范围核验。

## 验证与限制

本地核心测试121项：120通过，1项因Windows文件符号链接权限跳过。版本状态、安装恢复和登录限流界面已完成隔离验证，便携程序已实测启动。

此版本标记为预发布：尚未完成全部工具真实会话联调、干净环境安装矩阵和原生启停配置写入；程序未进行商业代码签名。来源未知的外部技能无法直接判断是否最新。详见仓库 README 和验收记录。

浏览器登录需要 Git Credential Manager；也可使用个人访问令牌。实际账号授权由使用者在 GitHub 官方页面完成。
