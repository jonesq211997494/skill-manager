# Skillspace 0.2.2 桌面交付版

修复更新、移除父技能时对只读子目录的保护缺口，以及详情关闭和重新扫描时的异步状态问题。沿用现有安装基线、快照和数据格式。

- Windows x64 安装版：`Skill-Manager-0.2.2-setup-x64.exe`。
- 免安装版：`Skill-Manager-0.2.2-portable.exe`。
- 校验值：`SHA256SUMS-0.2.2.txt`。

升级前关闭旧程序。两种版本均使用 `%APPDATA%/SkillManagerDesktop`，免安装版的数据不会跟随 EXE 移动。程序仍为未签名的开发预览版；干净系统安装、卸载和跨版本升级尚未完成验证。

本文件是发布说明草稿；本轮构建仅保存在本地，没有创建 GitHub Release。完整范围及测试证据见 [改进与交付记录](../改进记录-0.2.2.md)。
