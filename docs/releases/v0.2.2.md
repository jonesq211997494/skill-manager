# Skillspace 0.2.2 桌面交付版

Windows x64 中文技能管理器，用于管理 Codex、Claude Code 和 Cursor 技能。下载后无需另行安装 Node.js、Rust 或 WebView2。

## 下载

- **安装版**：`Skill-Manager-0.2.2-setup-x64.exe`，支持简体中文、选择安装目录、桌面快捷方式及卸载入口。
- **免安装版**：`Skill-Manager-0.2.2-portable.exe`，双击运行。
- **校验文件**：`SHA256SUMS-0.2.2.txt`。

## 本版改进

- 更新、移除父技能目录时保护其中的系统或插件只读子目录，并在执行前再次核验。
- 修复关闭详情后旧请求重新打开面板、扫描后详情和批量选择残留的问题。
- 修复 Windows 短路径中 `~` 与 `%7E` 的等价编码差异，避免便携版误拒绝自身页面的服务请求。
- 正常退出等待已确认的文件操作和管理数据回写；文件操作结果与索引刷新结果分别报告。
- 补齐生产 CSP、IPC 来源及参数检查、数据库格式预检，以及安装包和成品自动验证。

## 升级与数据

升级前先关闭旧程序。两种版本均使用 `%APPDATA%/SkillManagerDesktop`；免安装版的数据不会随 EXE 移动。需要备份时，关闭程序后备份整个数据目录。默认卸载保留应用数据与技能。

本版仍为未签名的开发预览版，没有自动更新。交互式安装向导、多显示器 DPI 切换及各工具真实会话的完整兼容矩阵尚未完成验收。
